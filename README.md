# Physik LK – Gleichungssammlung

Eine digitale Gleichungssammlung und Lernhilfe für den Physik-Leistungskurs.

## Funktionen

* Physikalische Formeln mit Erklärungen
* Suche und Kategorien
* Favoriten und zuletzt verwendete Formeln
* Eigene Formeln
* Übungs-LKs mit Aufgaben und automatischer Antwortprüfung
* Lösungswege und Punktestand
* Bearbeitungsmodus für Administratoren

## Technologie

* HTML, CSS und JavaScript
* Supabase
* KaTeX
* GitHub Pages

Erstellt als Lernhilfe für den Physik LK.
